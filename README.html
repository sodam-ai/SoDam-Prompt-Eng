1. 한눈에 보기

SoDam Prompt는 학생·직장인·일반인이 AI에게 글쓰기를 요청할 때 쓰는 10종 스킬 모음입니다. 스킬 하나 = 미리 설계된 질문 틀 하나. 빈칸에 내 상황을 채우면 AI가 완성글을 만들어 줍니다.

5. 빠른 시작

Claude.ai 앱에서 시작하기

Step 1: claude.ai 로그인 → 우측 상단 프로필 → Customize 클릭

Step 2: 왼쪽 메뉴 Skills 탭 클릭 → + Create skill 또는 + Add skill

Step 3: 압축을 푼 폴더의 skills 안에서 쓰고 싶은 스킬 폴더 하나(예: book-report-helper)를 ZIP으로 압축해 업로드합니다.

  • Windows: 그 폴더를 마우스 오른쪽 클릭 → ZIP 파일로 압축 (Windows 10은 보내기 → 압축(ZIP) 폴더)
  • Mac: 그 폴더를 마우스 오른쪽 클릭 → 압축
  • ZIP을 열었을 때 맨 위에 그 스킬 폴더가 보여야 합니다. 폴더 이름은 바꾸지 마세요. 여러 스킬을 쓰려면 하나씩 같은 방법으로 올립니다.

⚠️ ZIP 업로드는 직접 시험하지 않았습니다 (2026-11-26): 위 압축 형태는 Anthropic 공식 도움말을 기준으로 안내합니다. 같은 도움말에 따르면 Claude 설정에서 코드 실행(Code execution) 기능이 켜져 있어야 합니다. skills 폴더 전체나 저장소 전체를 압축하는 방법은 확인하지 않아 안내하지 않습니다.

Step 4: 토글을 ON (파란색)으로 변경

Step 5: 채팅창에서 자연어로 말하기:

독후감 써줘. 책 제목은 "어린 왕자", 느낀 점은 "어른도 아이 마음이 필요하다" 야.

Claude Code에서 시작하기

Step 1: 스킬 파일 복사 — 4장의 안내대로 skills 폴더가 보이는 위치에서 터미널을 연 뒤, 내 터미널에 맞는 한 묶음만 실행합니다.

⚠️ 같은 이름의 스킬이 이미 있으면 덮어씁니다. 직접 고친 스킬이 있다면 먼저 다른 곳에 복사해 두세요.

Windows (PowerShell)

New-Item -ItemType Directory -Force "$HOME\.claude\skills" | Out-Null
Copy-Item -Recurse -Force .\skills\* "$HOME\.claude\skills\"

Mac · Linux · Git Bash

mkdir -p ~/.claude/skills
cp -r ./skills/* ~/.claude/skills/

복사 확인 — 복사할 때 오류 문구가 없었는지 먼저 보고, 같은 위치(skills가 보이는 폴더)에서 아래를 실행합니다. 설치된 파일이 원본과 같을 때만 PowerShell은 True, bash는 OK가 나옵니다. (대표 스킬 1개만 비교합니다.) AI 도구가 스킬을 인식하는지는 Step 2·3에서 따로 확인하세요.

(Test-Path .\skills\book-report-helper\SKILL.md) -and (Test-Path "$HOME\.claude\skills\book-report-helper\SKILL.md") -and ((Get-FileHash .\skills\book-report-helper\SKILL.md).Hash -eq (Get-FileHash "$HOME\.claude\skills\book-report-helper\SKILL.md").Hash)
cmp ./skills/book-report-helper/SKILL.md ~/.claude/skills/book-report-helper/SKILL.md && echo OK

확인 범위(2026-11-26): 위 복사 명령은 Windows의 PowerShell 5.1과 Git Bash에서 임시 폴더를 대상으로 실행해 파일 위치를 확인했습니다. Mac · Linux에서의 실행과, 이 방법으로 복사한 뒤 Claude Code가 인식하는지는 이때 다시 확인하지 않았습니다.

Claude Code — 플러그인 정식 설치 (sodam-prompt:스킬명 형식)

sodam-prompt:book-report-helper처럼 저장소 이름이 붙는 형식으로 안정적으로 쓰고 싶다면, 폴더 복사 대신 Claude Code의 정식 플러그인 등록 기능을 쓰세요. 이 저장소는 .claude-plugin/plugin.json·marketplace.json에 더해 commands/ 폴더(모든 스킬과 1:1 대응)를 갖추고 있어 바로 등록할 수 있습니다.

왜 commands/ 폴더가 따로 있나요? Claude Code에는 알려진 제한(공식 이슈 #41842)이 있어서, skills/ 폴더만으로는 sodam-prompt: 접두사가 붙은 슬래시 명령어로 안정적으로 등록되지 않습니다. commands/ 폴더가 이 접두사 형식을 보장하는 검증된 방법입니다(같은 SoDam 계열의 다른 플러그인에서 실사용 확인됨).

/plugin marketplace add sodam-ai/SoDam-Prompt-Eng
/plugin install sodam-prompt@sodam-prompt-marketplace

설치 — 다운로드한 로컬 폴더로 등록 (GitHub 접근 없이도 가능):

/plugin marketplace add "다운로드한 SoDam-Prompt-Eng 폴더의 전체 경로"
/plugin install sodam-prompt@sodam-prompt-marketplace

설치 후에는 슬래시 명령어(/sodam-prompt:book-report-helper)와 자연어(“독후감 써줘”) 둘 다 됩니다.

업데이트 (예전에 설치한 경우) — 터미널에서 두 줄을 실행한 뒤 Claude Code를 다시 시작합니다:

claude plugin marketplace update sodam-prompt-marketplace
claude plugin update sodam-prompt@sodam-prompt-marketplace

다운로드한 로컬 폴더로 등록했다면 그 폴더의 내용을 새 파일로 먼저 바꾼 뒤 위 두 줄을 실행합니다.

폴더 복사로 설치했다면 새 파일을 받은 뒤 위의 복사 명령을 다시 실행합니다(같은 이름의 스킬은 덮어씁니다).

제거(재설치 테스트용):

/plugin uninstall sodam-prompt@sodam-prompt-marketplace
/plugin marketplace remove sodam-prompt-marketplace

터미널에서 직접 하려면: claude plugin uninstall sodam-prompt@sodam-prompt-marketplace (--prune 옵션은 더 이상 필요 없는 자동 설치 의존 항목까지 지우므로 여기서는 쓰지 않습니다)

깨끗하게 다시 설치하려면 위 제거 명령 2줄을 실행한 뒤, 설치 명령을 처음부터 다시 실행하세요.

정직한 안내: 위 명령어는 이 저장소에 실제로 있는 plugin.json(“name”: “sodam-prompt”)·marketplace.json(“name”: “sodam-prompt-marketplace”) 값과, Claude Code 공식 문서(/plugin uninstall·/plugin marketplace remove)를 근거로 합니다. 다만 이 명령을 새 세션에서 직접 실행해 결과 화면을 눈으로 확인하는 것은 사람만 할 수 있는 검증입니다 — 이 문서의 “실사용 테스트” 방식대로 새 세션을 열어 직접 확인해 주세요.

7. 스킬별 사용 방법 (10종 전부)

값이 두 개인 스킬은 아래에 적힌 순서대로 적으면 됩니다. 따옴표는 값이 어디까지인지 알려 주는 표시입니다. 값을 빠뜨리면 AI가 지어내지 않고 물어보도록 지시해 두었습니다. 이 입력 방식은 0.3.0부터입니다. 그전 버전은 /이름 "값1" "값2"로 부르면 지시문에서 값이 한 칸씩 밀렸습니다. 예전에 설치했다면 6장의 업데이트 방법을 따르세요.

스킬 1: 독후감-도우미

언제 쓰나요? 책을 읽고 독후감을 써야 할 때

필요한 정보:

  • 먼저: 책 제목
  • 그다음: 느낀 점 한 줄

예시:

/book-report-helper "어린 왕자" "어른도 아이 마음이 필요하다"

자연어로도 됩니다:

독후감 도와줘. 어린 왕자 읽었고 어른도 아이 마음이 필요하다고 느꼈어.

결과물: 3문단 독후감 (①읽기 전 기대 ②핵심 내용 ③느낀 점과 배운 것)

스킬 2: 정중한-메시지

언제 쓰나요? 선생님·상사·어른에게 메시지를 보낼 때

필요한 정보:

  • 먼저: 받는 사람 (예: 담임 선생님)
  • 그다음: 용건 한 줄 (예: 결석 사유 전달)

예시:

/polite-message "담임 선생님" "내일 병원 진료로 결석합니다"

결과물: 제목 + 정중한 본문 메시지

스킬 3: 긴글-3줄요약

언제 쓰나요? 긴 글을 핵심 3줄로 정리하고 싶을 때

필요한 정보:

  • 요약할 글 전체 (뒤에 적는 내용이 통째로 전달됩니다)

예시:

/long-text-summary [긴 글 전체 붙여넣기]

결과물: 핵심 내용 3줄 (• 기호로 정리)

스킬 4: 쉽게-설명해줘

언제 쓰나요? 어려운 개념을 누군가에게 쉽게 설명해야 할 때

필요한 정보:

  • 먼저: 설명할 개념 (예: 광합성)
  • 그다음: 듣는 사람 나이 (예: 10살)

예시:

/explain-simply "광합성" "10살"

결과물: 비유 1개 + 쉬운 말 3문장 설명

스킬 5: 공부-계획표

언제 쓰나요? 시험 준비나 공부 계획을 세울 때

필요한 정보:

  • 먼저: 과목·목표 (예: 수학 중간고사 80점)
  • 그다음: 기간 (예: 2주)

예시:

/study-planner "수학 중간고사 80점" "2주"

결과물: 요일별 공부 계획표 (하루 분량 포함)

스킬 6: 자기소개-다듬기

언제 쓰나요? 자기소개를 써야 하는데 어떻게 쓸지 모를 때

필요한 정보:

  • 먼저: 내 소개 메모 (짧게라도 OK)
  • 그다음: 쓸 곳 (예: 동아리 지원서)

예시:

/self-intro-polish "이름 김민준, 축구 좋아함, 성실함" "동아리 지원서"

결과물: 상황에 맞게 다듬어진 자기소개 완성본

스킬 7: sns-캡션

언제 쓰나요? 인스타그램·페이스북 등 SNS에 글을 올릴 때

필요한 정보:

  • 먼저: 상황 (예: 친구들과 카페에서 공부)
  • 그다음: 분위기 (예: 따뜻하고 즐거운)

예시:

/sns-caption "친구들과 카페에서 공부" "따뜻하고 즐거운"

결과물: 캡션 2가지 버전 + 해시태그 5개

스킬 8: 영어-자연스럽게

언제 쓰나요? 한국어를 자연스러운 영어로 바꾸고 싶을 때

필요한 정보:

  • 한국어 문장 (뒤에 적는 내용이 통째로 전달됩니다)

예시:

/natural-english "나는 오늘 학교에서 발표를 잘 했어"

결과물: 자연스러운 영어 문장 + 왜 그렇게 표현하는지 한국어 설명

스킬 9: 발표-대본

언제 쓰나요? 발표 내용을 대본으로 정리해야 할 때

필요한 정보:

  • 먼저: 발표 주제 (예: 환경 보호의 중요성)
  • 그다음: 발표 시간 (예: 5분)

예시:

/presentation-script "환경 보호의 중요성" "5분"

결과물: 도입–본론–마무리 대본 (읽는 시간 포함)

스킬 10: 부탁-사과-메시지

언제 쓰나요? 부탁하거나 사과하는 메시지를 써야 할 때

필요한 정보:

  • 먼저: 상황 (예: 숙제 제출이 늦었음)
  • 그다음: 상대와의 관계 (예: 선생님)

예시:

/request-apology-message "숙제 제출이 하루 늦었음" "선생님"

결과물: 정중한 버전 + 친근한 버전 2가지

13. 문제 · 오류 대처 방법

Q1. 슬래시 명령어 /book-report-helper 가 나타나지 않아요

원인: 스킬 파일이 올바른 위치에 없거나 Claude Code를 재시작해야 함

해결:

  1. 스킬 파일 위치 확인:

    ls ~/.claude/skills/

    book-report-helper 폴더가 보여야 합니다.

  2. 한 스킬만 없으면 14장 FAQ의 스킬 1개 설치 명령을, 전부 없으면 5장 Step 1의 명령을 씁니다 (폴더를 만드는 첫 줄까지 함께). 전체 복사는 같은 이름의 스킬을 모두 덮어씁니다.

  3. Claude Code 종료 후 재시작:

    claude

Q2. 자연어로 말했는데 스킬을 안 쓰고 일반 답변만 해요

원인: 자연어 매칭은 AI가 상황을 판단합니다. 더 구체적으로 말하면 됩니다.

해결: 더 직접적으로 요청하세요:

독후감 스킬 써서 독후감 써줘. 책: 어린 왕자, 느낀 점: 어른도 아이 마음이 필요해

또는 슬래시 명령어를 직접 쓰세요:

/book-report-helper "어린 왕자" "어른도 아이 마음이 필요해"

Q3. Claude.ai 앱에서 ZIP 업로드가 안 돼요

원인: 파일 형식 또는 크기 문제

해결:

  1. ZIP을 열었을 때 맨 위에 스킬 폴더 하나(예: book-report-helper)가 있고 그 안에 SKILL.md가 있는지 확인 (5장 Step 3 — 공식 도움말 기준이며 업로드는 직접 시험하지 않음)
  2. Claude 설정에서 코드 실행(Code execution) 기능이 켜져 있는지 확인
  3. 브라우저 새로고침 후 재시도
  4. 다른 브라우저(크롬→엣지) 시도

Q4. 결과가 이상해요 / 기대와 달라요

원인: AI 결과물은 매번 조금씩 달라질 수 있습니다.

해결:

  1. 더 구체적인 정보를 입력하세요 (짧은 힌트보다 상세한 내용이 좋습니다)
  2. 마음에 안 들면 “다시 써줘” 또는 “더 쉽게 써줘” 요청
  3. 같은 스킬을 다시 실행하면 다른 버전이 나올 수 있습니다

Q5. cp: no such file · is not a directory 오류가 나거나, 복사했는데 스킬이 안 보여요

원인: ① skills 폴더가 보이지 않는 위치에서 명령을 실행했거나 ② 대상 폴더(.claude/skills)를 만들지 않고 복사한 경우입니다. ②는 오류 없이 끝나도 파일이 잘못된 위치에 놓일 수 있습니다.

해결: 4장대로 터미널 위치를 맞춘 뒤, 5장 Step 1의 두 줄을 순서대로 다시 실행합니다.

잘못 복사된 흔적 확인: 정상 위치는 .claude/skills/스킬이름/SKILL.md입니다. .claude/skills 바로 아래에 SKILL.md 파일이 있다면 이전의 복사가 잘못된 것일 수 있습니다. 내용이 이 저장소의 스킬과 같아 보여도 그것만으로 잘못 복사된 파일이라고 단정할 수는 없습니다. 지우지 말고 .claude 밖의 다른 폴더로 옮겨 둔 뒤 설치를 다시 확인하세요.

Q6. Windows에서 설치 명령이 안 돼요

원인: 명령 프롬프트(cmd)에서는 위 명령이 동작하지 않습니다. 또 bash용 명령에 C:\... 같은 Windows 경로를 넣으면 \가 사라져 경로가 깨집니다.

해결: PowerShell에서 실행합니다.

New-Item -ItemType Directory -Force "$HOME\.claude\skills" | Out-Null
Copy-Item -Recurse -Force .\skills\* "$HOME\.claude\skills\"

또는 파일 탐색기에서 직접 복사:

  1. skills 폴더 안의 모든 폴더 선택 → Ctrl+C
  2. C:\Users\사용자명\.claude\skills\ 폴더 열기(skills 폴더가 없으면 새로 만들기) → Ctrl+V

Q7. 한글 폴더명이 깨져요

원인: 터미널 인코딩 문제

해결:

# UTF-8 설정 확인
chcp 65001   # Windows CMD 기준

또는 파일 탐색기를 사용해 직접 폴더를 복사하세요.

14. FAQ — 자주 묻는 질문

Q: 무료로 쓸 수 있나요? A: 이 스킬 파일 자체는 무료(Apache-2.0)입니다. AI 사용 요금은 Claude·OpenAI 등 가입한 서비스의 요금제를 따릅니다. Claude 무료 플랜으로도 사용 가능합니다.

Q: 인터넷이 없어도 되나요? A: 아니요. AI 모델이 인터넷(AI 회사 서버)에 연결되어야 합니다. SKILL.md 파일은 로컬에 있지만, 실제 글 생성은 서버에서 이루어집니다.

Q: 스마트폰에서도 쓸 수 있나요? A: Claude.ai 앱(웹 버전)은 스마트폰 브라우저에서도 작동합니다. 다만 스킬 업로드는 컴퓨터에서 하는 것이 편합니다.

Q: 10개 중 일부만 설치할 수 있나요? A: 네. 원하는 스킬 폴더만 골라서 복사하면 됩니다. skills 폴더가 보이는 위치(4장)에서 실행하세요.

⚠️ 같은 이름의 스킬이 이미 있으면 덮어씁니다. 직접 고친 스킬은 먼저 다른 곳에 복사해 두세요.

Windows (PowerShell)

New-Item -ItemType Directory -Force "$HOME\.claude\skills" | Out-Null
Copy-Item -Recurse -Force .\skills\book-report-helper "$HOME\.claude\skills\"

Mac · Linux · Git Bash

mkdir -p ~/.claude/skills
cp -r ./skills/book-report-helper ~/.claude/skills/

다른 스킬은 book-report-helper 자리에 폴더 이름을 바꿔 마지막 줄만 한 번 더 실행합니다.

Q: 새 스킬을 직접 만들 수 있나요? A: 네. skills/ 폴더에 새 폴더를 만들고 SKILL.md 파일을 작성하면 됩니다. 형식은 기존 파일을 참고하세요.

Q: 결과물을 상업적으로 사용해도 되나요? A: AI가 생성한 텍스트의 상업적 사용은 각 AI 서비스(Anthropic, OpenAI 등)의 이용약관을 따릅니다. 이 스킬 파일 자체의 수정·배포는 Apache-2.0 조건 하에 상업적으로도 허용됩니다. 자세한 내용은 15장 참조.

Q: 이 스킬이 내 개인 데이터를 학습에 사용하나요? A: 이 스킬 파일 자체는 데이터를 수집하지 않습니다. AI 서비스의 학습 데이터 사용 정책은 각 서비스(Anthropic, OpenAI 등)의 정책에 따릅니다.

Q: Windows · Mac · Linux 모두 되나요? A: SKILL.md는 텍스트 파일이라 파일 자체는 운영체제와 상관없습니다. 다만 설치 복사 명령을 직접 시험한 환경은 Windows(PowerShell 5.1·Git Bash)의 임시 폴더뿐이며, Mac·Linux에서는 확인하지 않았습니다.

Q: 스킬을 삭제하고 싶어요 A: 설치한 그 스킬 폴더만 지우면 됩니다. 직접 고친 내용도 함께 지워지고 휴지통으로 가지 않으니, 폴더 이름과 내용을 먼저 확인하세요. 이전 안내로 Codex에 설치했다면 ~/.codex/skills에 있을 수 있으니, 지우기 전에 실제 위치를 먼저 확인하세요. 아래는 Claude Code 기준이며, Codex에 설치했다면 .claude를 .agents로 바꿉니다. 대상 폴더가 없으면 오류가 표시됩니다.

Windows (PowerShell):

Remove-Item -Recurse "$HOME\.claude\skills\book-report-helper"

Mac · Linux · Git Bash:

rm -r ~/.claude/skills/book-report-helper

Claude.ai 앱: Customize → Skills → 해당 스킬 → 삭제

Q: 업데이트가 있으면 어떻게 알아요? A: GitHub 저장소(sodam-ai/SoDam-Prompt-Eng)에서 Watch 또는 Star를 눌러두면 업데이트 알림을 받을 수 있습니다.

Q: 오류나 개선 사항을 어떻게 알려요? A: GitHub Issues 탭에서 새 이슈를 열어주세요. 한국어로 작성해도 됩니다.
