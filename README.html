1. 한눈에 보기

SoDam Prompt는 학생·직장인·일반인이 AI에게 글쓰기를 요청할 때 쓰는 10종 스킬 모음입니다. 스킬 하나 = 미리 설계된 질문 틀 하나. 빈칸에 내 상황을 채우면 AI가 완성글을 만들어 줍니다.

번호 스킬 이름 필요한 정보 결과물
1 독후감-도우미 책 제목, 느낀 점 한 줄 3문단 독후감
2 정중한-메시지 받는 사람, 용건 한 줄 제목+본문 메시지
3 긴글-3줄요약 요약할 글 전체 핵심 3줄 요약
4 쉽게-설명해줘 개념, 듣는 사람 나이 비유+3문장 설명
5 공부-계획표 과목·목표, 기간 요일별 공부 계획표
6 자기소개-다듬기 내 소개 메모, 쓸 곳 완성된 자기소개
7 sns-캡션 상황, 분위기 캡션 2개 + 해시태그 5개
8 영어-자연스럽게 한국어 문장 자연스러운 영어+이유 설명
9 발표-대본 주제, 발표 시간 도입-본론-마무리 대본
10 부탁-사과-메시지 상황, 상대 관계 정중한·친근한 2가지 버전

비용: $0 (AI 사용 요금은 각자 가입한 Claude/Codex 요금제 기준) 서버: 없음 (내 컴퓨터 + AI 회사 서버 사이에서만 작동) 코드 실행: 없음 (텍스트 질문·답변만 오갑니다)

2. 사전 준비물

스킬을 사용하려면 아래 중 하나만 있으면 됩니다. 전부 필요하지 않습니다.

계정 만들기 (Claude.ai 방법 기준)

  1. 인터넷 브라우저(크롬, 엣지 등)를 엽니다
  2. 주소창에 claude.ai 를 입력하고 Enter
  3. Sign up 버튼 클릭 → 이메일 주소 입력 → 비밀번호 설정
  4. 이메일로 온 인증 메일 확인 → 로그인 완료

만 14세 미만은 보호자와 함께 가입해야 합니다. 대한민국 거주자를 대상으로 만든 도구입니다.

3. 필요 프로그램 설치

방법 A — Claude.ai 앱 (터미널 불필요, 가장 쉬움)

별도 프로그램 설치 없이 인터넷 브라우저만 있으면 됩니다. → 4단계(다운로드)로 바로 이동하세요.

방법 B — Claude Code (개발자·고급 사용자)

Node.js 설치 확인

Node.js가 이미 설치되어 있는지 확인합니다.

Windows 기준: 1. 키보드 Windows키 + R → cmd 입력 → Enter (검은 창이 열림) 2. 아래를 입력하고 Enter: node --version 3. v18.0.0 이상이 표시되면 OK. 아무것도 안 나오면 설치 필요.

Node.js 설치 (없는 경우)

  1. 브라우저에서 nodejs.org 접속
  2. LTS 버전 다운로드 버튼 클릭
  3. 다운로드된 파일 더블클릭 → 설치 마법사 따라 Next → Finish

Claude Code 설치

검은 창(터미널)에 입력:

npm install -g @anthropic-ai/claude-code

설치 확인:

claude --version

버전 번호가 나오면 성공.

4. 다운로드 방법

스킬 파일 다운로드

방법 1: ZIP 다운로드 (가장 쉬움)

  1. 이 저장소 페이지에서 초록색 Code 버튼 클릭
  2. Download ZIP 클릭
  3. 내 컴퓨터의 원하는 폴더에 압축 풀기
  4. SoDam-Prompt-Eng-main 폴더가 생깁니다

방법 2: git clone (git이 설치된 경우)

검은 창에서:

git clone https://github.com/sodam-ai/SoDam-Prompt-Eng.git
cd SoDam-Prompt-Eng

설치 전 확인 (안전 체크)

  • ✅ 무코드 (★ Safe) — 이 저장소의 스킬 10개는 전부 순수 텍스트입니다. 셸 명령·프로그램 실행·외부 도구 호출이 전혀 없습니다.
  • ✅ 출처 확인 — 반드시 공식 저장소(sodam-ai/SoDam-Prompt-Eng)에서만 받으세요. 다른 곳에서 받은 파일은 내용이 다를 수 있습니다.
  • ✅ 미리보기 가능 — 설치 전에 GitHub에서 skills/<이름>/SKILL.md 파일을 직접 클릭해 내용을 확인할 수 있습니다.

5. 빠른 시작

Claude.ai 앱에서 5분 안에 시작하기

Step 1: claude.ai 로그인 → 우측 상단 프로필 → Customize 클릭

Step 2: 왼쪽 메뉴 Skills 탭 클릭 → + Create skill 또는 + Add skill

Step 3: 압축 푼 폴더 전체를 ZIP으로 다시 압축하거나, skills 폴더를 ZIP으로 압축 → 업로드

Step 4: 토글을 ON (파란색)으로 변경

Step 5: 채팅창에서 자연어로 말하기:

독후감 써줘. 책 제목은 "어린 왕자", 느낀 점은 "어른도 아이 마음이 필요하다" 야.

AI가 자동으로 독후감-도우미 스킬을 사용해 독후감을 만들어줍니다.

7. 스킬별 사용 방법 (10종 전부)

스킬 1: 독후감-도우미

언제 쓰나요? 책을 읽고 독후감을 써야 할 때

필요한 정보: - $1: 책 제목 - $2: 느낀 점 한 줄

예시:

/독후감-도우미 "어린 왕자" "어른도 아이 마음이 필요하다"

자연어로도 됩니다:

독후감 도와줘. 어린 왕자 읽었고 어른도 아이 마음이 필요하다고 느꼈어.

결과물: 3문단 독후감 (①읽기 전 기대 ②핵심 내용 ③느낀 점과 배운 것)

스킬 2: 정중한-메시지

언제 쓰나요? 선생님·상사·어른에게 메시지를 보낼 때

필요한 정보: - $1: 받는 사람 (예: 담임 선생님) - $2: 용건 한 줄 (예: 결석 사유 전달)

예시:

/정중한-메시지 "담임 선생님" "내일 병원 진료로 결석합니다"

결과물: 제목 + 정중한 본문 메시지

스킬 3: 긴글-3줄요약

언제 쓰나요? 긴 글을 핵심 3줄로 정리하고 싶을 때

필요한 정보: - $1: 요약할 글 전체

예시:

/긴글-3줄요약 [긴 글 전체 붙여넣기]

결과물: 핵심 내용 3줄 (• 기호로 정리)

스킬 4: 쉽게-설명해줘

언제 쓰나요? 어려운 개념을 누군가에게 쉽게 설명해야 할 때

필요한 정보: - $1: 설명할 개념 (예: 광합성) - $2: 듣는 사람 나이 (예: 10살)

예시:

/쉽게-설명해줘 "광합성" "10살"

결과물: 비유 1개 + 쉬운 말 3문장 설명

스킬 5: 공부-계획표

언제 쓰나요? 시험 준비나 공부 계획을 세울 때

필요한 정보: - $1: 과목·목표 (예: 수학 중간고사 80점) - $2: 기간 (예: 2주)

예시:

/공부-계획표 "수학 중간고사 80점" "2주"

결과물: 요일별 공부 계획표 (하루 분량 포함)

스킬 6: 자기소개-다듬기

언제 쓰나요? 자기소개를 써야 하는데 어떻게 쓸지 모를 때

필요한 정보: - $1: 내 소개 메모 (짧게라도 OK) - $2: 쓸 곳 (예: 동아리 지원서)

예시:

/자기소개-다듬기 "이름 김민준, 축구 좋아함, 성실함" "동아리 지원서"

결과물: 상황에 맞게 다듬어진 자기소개 완성본

스킬 7: sns-캡션

언제 쓰나요? 인스타그램·페이스북 등 SNS에 글을 올릴 때

필요한 정보: - $1: 상황 (예: 친구들과 카페에서 공부) - $2: 분위기 (예: 따뜻하고 즐거운)

예시:

/sns-캡션 "친구들과 카페에서 공부" "따뜻하고 즐거운"

결과물: 캡션 2가지 버전 + 해시태그 5개

스킬 8: 영어-자연스럽게

언제 쓰나요? 한국어를 자연스러운 영어로 바꾸고 싶을 때

필요한 정보: - $1: 한국어 문장

예시:

/영어-자연스럽게 "나는 오늘 학교에서 발표를 잘 했어"

결과물: 자연스러운 영어 문장 + 왜 그렇게 표현하는지 한국어 설명

스킬 9: 발표-대본

언제 쓰나요? 발표 내용을 대본으로 정리해야 할 때

필요한 정보: - $1: 발표 주제 (예: 환경 보호의 중요성) - $2: 발표 시간 (예: 5분)

예시:

/발표-대본 "환경 보호의 중요성" "5분"

결과물: 도입–본론–마무리 대본 (읽는 시간 포함)

스킬 10: 부탁-사과-메시지

언제 쓰나요? 부탁하거나 사과하는 메시지를 써야 할 때

필요한 정보: - $1: 상황 (예: 숙제 제출이 늦었음) - $2: 상대와의 관계 (예: 선생님)

예시:

/부탁-사과-메시지 "숙제 제출이 하루 늦었음" "선생님"

결과물: 정중한 버전 + 친근한 버전 2가지

13. 문제 · 오류 대처 방법

Q1. 슬래시 명령어 /독후감-도우미 가 나타나지 않아요

원인: 스킬 파일이 올바른 위치에 없거나 Claude Code를 재시작해야 함

해결: 1. 스킬 파일 위치 확인: bash ls ~/.claude/skills/ 독후감-도우미 폴더가 보여야 합니다.

  1. 없으면 다시 복사:

    cp -r ./skills/* ~/.claude/skills/

  2. Claude Code 종료 후 재시작:

    claude

Q2. 자연어로 말했는데 스킬을 안 쓰고 일반 답변만 해요

원인: 자연어 매칭은 AI가 상황을 판단합니다. 더 구체적으로 말하면 됩니다.

해결: 더 직접적으로 요청하세요:

독후감 스킬 써서 독후감 써줘. 책: 어린 왕자, 느낀 점: 어른도 아이 마음이 필요해

또는 슬래시 명령어를 직접 쓰세요:

/독후감-도우미 "어린 왕자" "어른도 아이 마음이 필요해"

Q3. Claude.ai 앱에서 ZIP 업로드가 안 돼요

원인: 파일 형식 또는 크기 문제

해결: 1. ZIP 파일이 올바르게 압축되었는지 확인 2. skills 폴더만 압축하거나 저장소 전체를 ZIP으로 다운로드해 업로드 시도 3. 브라우저 새로고침 후 재시도 4. 다른 브라우저(크롬→엣지) 시도

Q4. 결과가 이상해요 / 기대와 달라요

원인: AI 결과물은 매번 조금씩 달라질 수 있습니다.

해결: 1. 더 구체적인 정보를 입력하세요 (짧은 힌트보다 상세한 내용이 좋습니다) 2. 마음에 안 들면 “다시 써줘” 또는 “더 쉽게 써줘” 요청 3. 같은 스킬을 다시 실행하면 다른 버전이 나올 수 있습니다

Q5. cp: no such file 오류가 나요

원인: 경로가 틀렸거나 .claude/skills 폴더가 없음

해결:

# 폴더 먼저 만들기
mkdir -p ~/.claude/skills

# 다시 복사
cp -r ./skills/* ~/.claude/skills/

Q6. Windows에서 cp 명령어가 안 돼요

원인: Windows 기본 터미널(PowerShell/CMD)은 cp 대신 Copy-Item 사용

해결 (PowerShell):

Copy-Item -Recurse .\skills\* $env:USERPROFILE\.claude\skills\

또는 파일 탐색기에서 직접 복사: 1. skills 폴더 안의 모든 폴더 선택 → Ctrl+C 2. C:\Users\사용자명\.claude\skills\ 폴더 열기 → Ctrl+V

Q7. 한글 폴더명이 깨져요

원인: 터미널 인코딩 문제

해결:

# UTF-8 설정 확인
chcp 65001   # Windows CMD 기준

또는 파일 탐색기를 사용해 직접 폴더를 복사하세요.

Q: 무료로 쓸 수 있나요? A: 이 스킬 파일 자체는 무료(Apache-2.0)입니다. AI 사용 요금은 Claude·OpenAI 등 가입한 서비스의 요금제를 따릅니다. Claude 무료 플랜으로도 사용 가능합니다.

Q: 스마트폰에서도 쓸 수 있나요? A: Claude.ai 앱(웹 버전)은 스마트폰 브라우저에서도 작동합니다. 다만 스킬 업로드는 컴퓨터에서 하는 것이 편합니다.

Q: 10개 중 일부만 설치할 수 있나요? A: 네. 원하는 스킬 폴더만 골라서 복사하면 됩니다:

cp -r ./skills/독후감-도우미 ~/.claude/skills/
cp -r ./skills/정중한-메시지 ~/.claude/skills/

Q: 새 스킬을 직접 만들 수 있나요? A: 네. skills/ 폴더에 새 폴더를 만들고 SKILL.md 파일을 작성하면 됩니다. 형식은 기존 파일을 참고하세요.

Q: 결과물을 상업적으로 사용해도 되나요? A: AI가 생성한 텍스트의 상업적 사용은 각 AI 서비스(Anthropic, OpenAI 등)의 이용약관을 따릅니다. 이 스킬 파일 자체의 수정·배포는 Apache-2.0 조건 하에 상업적으로도 허용됩니다. 자세한 내용은 15장 참조.

Q: 이 스킬이 내 개인 데이터를 학습에 사용하나요? A: 이 스킬 파일 자체는 데이터를 수집하지 않습니다. AI 서비스의 학습 데이터 사용 정책은 각 서비스(Anthropic, OpenAI 등)의 정책에 따릅니다.

Q: Windows · Mac · Linux 모두 되나요? A: 네. SKILL.md 파일은 텍스트 파일이므로 운영체제 무관합니다. 설치 명령어만 OS에 맞게 쓰면 됩니다.

Q: 스킬을 삭제하고 싶어요 A: 설치한 폴더를 지우면 됩니다:

rm -rf ~/.claude/skills/독후감-도우미

Claude.ai 앱: Customize → Skills → 해당 스킬 → 삭제

Q: 다른 언어(영어, 일본어 등)로도 쓸 수 있나요? A: 스킬 본문은 한국어 출력으로 설계되었습니다. 영어 입력에도 반응하지만, 결과는 한국어로 나올 수 있습니다. 다국어 버전은 별도 스킬로 만들어야 합니다.
