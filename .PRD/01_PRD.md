## 1. 제품 개요

### 한 줄 요약
코딩도 AI도 처음인 사람이 **GitHub에서 내려받아 → 내 AI 도구에 설치하고 → 빈칸만 채워 → 바로 결과를 보는** SKILL.md 플러그인 모음.

### 해결하는 문제
지금 시중 프롬프트 자료·서비스는 전부 **개발자·중급자 눈높이**다. 완전 초보(비개발자, 10대, AI 처음, IT 비숙련)는 ① 빈 입력창 앞에서 막히고 ② 좋은 프롬프트를 받아도 복사만 하고 끝이며 ③ "이게 진짜 작동하는지" 판단을 못 한다.

### 핵심 가치
> **"프롬프트를 파는 게 아니라, 설치해서 반복 쓰는 능력을 준다."**

1. **빈칸만 채우면 끝** — 빈 입력창 대신 `argument-hint`로 안내되는 2~3칸. (Mad Libs 패턴)
2. **설치하면 영속 재사용** — `/이름 값1 값2` 로 언제든 다시 쓴다. "복붙 무덤" 탈출.
3. **무코드 ZIP 설치(★1)** — Claude.ai 앱 GUI에서 ZIP 업로드, 터미널 불필요.
4. **순수 텍스트, 코드 실행 없음** — 셸 명령·MCP 훅·개인정보 수집 없음. 초보 안전.

> **배포 채널**: GitHub 저장소가 곧 마켓플레이스다.
> 발견 → ZIP 다운로드 → GUI 업로드 → `/독후감-도우미 "어린왕자" "감동적이었어"` 호출.
> 상세 설계 → [05_MARKETPLACE_PLUGIN.md](./05_MARKETPLACE_PLUGIN.md)

## 2. 사용자

### 주요 사용자
- **누구**: 비개발자, 일반인, **만 14세 이상** 10대 학생, AI로만 자연어 개발하는 바이브코더, AI 처음인 사람.
- **상황**: "AI로 뭔가 해보고 싶은데 어떻게 시켜야 할지 모를 때". Claude Code / Codex / Claude.ai 앱 사용자. **MVP는 한국어 사용자.**
- **목표**: 어려운 공부 없이 **5분 안에 쓸 만한 결과물 하나**를 직접 뽑아보는 것.

### 사용자 시나리오 (대표)
1. 민지(15세)가 GitHub에서 README.md를 보고 "독후감-도우미"를 발견한다.
2. ZIP 다운로드 → Claude.ai 앱 Customize → Skills → ZIP 업로드 → 토글 ON.
3. "독후감 써줘"라고 말하면 자동으로 스킬이 작동해 결과가 나온다.
4. Claude Code 사용자는 `/독후감-도우미 "어린 왕자" "감동적이었어"` 로 호출.

## 3. 핵심 기능

| 기능 | 설명 | 우선순위 |
|------|------|----------|
| **SKILL.md 10개** | 사람이 검수한 시작 스킬 (빈칸 2~3개, 무코드) | P1 ✅ done |
| **README 설치 안내** | 3가지 경로(Claude.ai ZIP / Claude Code / Codex) + 왕초보용 | P1 ✅ done |
| **Claude.ai ZIP 무코드 설치** | ZIP 업로드 → 토글 ON → 자연어로 자동 호출 | P1 ✅ |
| **Claude Code 설치** | `cp -r skills/* ~/.claude/skills/` → `/이름 값` 호출 | P1 ✅ |
| **Codex 설치** | `cp -r skills/* ~/.codex/skills/` → `$이름` 호출 | P1 ✅ |
| **작동 검증 배지(사람 검수)** | Haiku 4.5에서 실제 작동 확인 "✅ 사람 검수" | P1 (pending) |
| **작동 검증 자동화** | promptfoo로 재테스트 → 작동률 숫자 표시 | P2 |
| **Claude Code 마켓 등록** | `/plugin install <이름>@sodam` 한 줄 설치 | P2 ✅ 등록 완료(라이브 재검증 대기) |
| **스킬 수 확장** | 10개 → 커뮤니티 기여 수용 | P3 |

## 4. 사용자 흐름 (User Flow)

```
[GitHub README 발견]
  → [ZIP 다운로드]
  → [설치: Claude.ai 앱 ZIP(★1) / Claude Code cp(★2) / Codex cp(★2)]
  → [스킬 사용: 자연어 자동 / /이름 값1 값2 / $이름]
  → [결과 확인 → 복사 → 반복 사용]
```

초보 최단 경로(★1):
1. GitHub → Code → Download ZIP
2. Claude.ai 앱 → Customize → Skills → + Create skill → ZIP 업로드 → 토글 ON
3. "독후감 써줘" → 결과

## 5. 성공 기준 (KPI)

- [ ] **설치 성공**: Claude.ai 앱 ZIP 설치 후 스킬 1개 작동 ≤ 5분.
- [ ] **작동 확인**: 10개 SKILL.md 전부 Claude Haiku 4.5에서 실제 결과 생성됨.
- [ ] **안전**: 개인정보(이름·전화·주소·계좌) 입력 유도 없음 확인.
- [ ] **안전**: 위험·민감 주제(의료·법률·금융·자해·성인) 없음 확인.
- [ ] **이해도**: 비개발자가 README 보고 5분 안에 설치 완료 가능.
- [ ] **비용**: 서버 없음 → 운영 비용 $0.
