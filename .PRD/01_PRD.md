## 1. 제품 개요

### 한 줄 요약
코딩도 AI도 처음인 사람이 **GitHub에서 내려받아 → 내 AI 도구에 설치하고 → 빈칸만 채워 → 바로 결과를 보는** SKILL.md 플러그인 모음.

### 해결하는 문제
지금 시중 프롬프트 자료·서비스는 전부 **개발자·중급자 눈높이**다. 완전 초보(비개발자, 10대, AI 처음, IT 비숙련)는 ① 빈 입력창 앞에서 막히고 ② 좋은 프롬프트를 받아도 복사만 하고 끝이며 ③ "이게 진짜 작동하는지" 판단을 못 한다.

### 핵심 가치
> **"프롬프트를 파는 게 아니라, 설치해서 반복 쓰는 능력을 준다."**

1. **빈칸만 채우면 끝** — 빈 입력창 대신 `argument-hint`로 안내되는 2~3칸. (Mad Libs 패턴)
2. **설치하면 영속 재사용** — `/이름 값1 값2` 로 언제든 다시 쓴다. "복붙 무덤" 탈출.
3. **무코드 ZIP 설치(★1)** — Claude.ai 앱 GUI에서 ZIP 업로드, 터미널 불필요.
4. **순수 텍스트, 코드 실행 없음** — 셸 명령·MCP 훅·개인정보 수집 없음. 초보 안전.

> **배포 채널**: GitHub 저장소가 곧 마켓플레이스다.
> 발견 → ZIP 다운로드 → 압축 풀기 → 스킬 폴더 하나를 다시 ZIP으로 압축 → GUI 업로드 → 자연어("독후감 써줘") 또는 `/book-report-helper "어린 왕자" "감동적이었어"` 호출.
> (2026-11-26 정정: 폴더명이 영문으로 바뀌어 호출 예시 갱신. **ZIP 업로드 단계는 실행 확인 기록이 없다** — §3 표 참조)
> 상세 설계 → [05_MARKETPLACE_PLUGIN.md](./05_MARKETPLACE_PLUGIN.md)

## 2. 사용자

### 주요 사용자
- **누구**: 비개발자, 일반인, **만 14세 이상** 10대 학생, AI로만 자연어 개발하는 바이브코더, AI 처음인 사람.
- **상황**: "AI로 뭔가 해보고 싶은데 어떻게 시켜야 할지 모를 때". Claude Code / Codex / Claude.ai 앱 사용자. **MVP는 한국어 사용자.**
- **목표**: 어려운 공부 없이 **5분 안에 쓸 만한 결과물 하나**를 직접 뽑아보는 것.

### 사용자 시나리오 (대표)
1. 민지(15세)가 GitHub에서 README.md를 보고 "독후감-도우미"를 발견한다.
2. ZIP 다운로드·압축 풀기 → `skills` 안의 스킬 폴더 하나를 ZIP으로 압축 → Claude.ai 앱 Customize → Skills → 업로드 → 토글 ON.
3. "독후감 써줘"라고 말하면 자동으로 스킬이 작동해 결과가 나온다.
4. Claude Code 사용자는 `/book-report-helper "어린 왕자" "감동적이었어"`(직접 복사 설치) 또는 `/sodam-prompt:book-report-helper`(플러그인 설치)로 호출.

## 4. 사용자 흐름 (User Flow)

```
[GitHub README 발견]
  → [ZIP 다운로드 → 압축 풀기]
  → [설치: Claude.ai 앱(★1, 스킬 폴더 하나를 새로 ZIP) / Claude Code cp(★2) / Codex cp(★2)]
  → [스킬 사용: 자연어 자동 / /이름 값1 값2 / $이름]
  → [결과 확인 → 복사 → 반복 사용]
```

초보 최단 경로(★1):
1. GitHub → Code → Download ZIP → 압축 풀기 → `skills` 안의 **스킬 폴더 하나**를 ZIP으로 압축 (2026-11-26 정정: 저장소 ZIP을 그대로 올리지 않는다. 공식 도움말 기준, 업로드 미확인)
2. Claude.ai 앱 → Customize → Skills → + Create skill → 그 ZIP 업로드 → 토글 ON
3. "독후감 써줘" → 결과

## 5. 성공 기준 (KPI)

- [ ] **설치 성공**: Claude.ai 앱 ZIP 설치 후 스킬 1개 작동 ≤ 5분. (ZIP 업로드 설치 자체가 실행 확인 전이고, "5분" 타이머 실측 기록도 없음 — 미확정으로 유지, 2026-11-26 정정)
- [x] **작동 확인**: 10개 SKILL.md 전부 Claude Haiku 4.5에서 실제 결과 생성됨. (2026-07-13~14 실행테스트 10/10 완료)
- [x] **안전**: 개인정보(이름·전화·주소·계좌) 입력 유도 없음 확인. (10개 전부 문구 존재 + 공격 테스트 3건 방어 성공)
- [x] **안전**: 위험·민감 주제(의료·법률·금융·자해·성인) 없음 확인. (10개 전부 내용 확인, 0건)
- [ ] **이해도**: 비개발자가 README 보고 5분 안에 설치 완료 가능. (사용자 본인이 실사용 중이나 "5분" 타이머 실측 기록은 없음 — 미확정으로 유지)
- [x] **비용**: 서버 없음 → 운영 비용 $0. (구조적으로 항상 참 — 서버/DB/인증 자체가 없음)
