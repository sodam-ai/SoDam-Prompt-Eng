## SKILL.md 표준 (절대 하지 마 / 항상 해)

### 절대 하지 마 (DO NOT)

- `!cmd`, `exec()`, `spawn()` 같은 셸 실행 명령 포함하지 마
- 개인정보(이름·전화·주소·계좌·주민번호) 입력 유도하지 마
- 위험·민감 주제(자해·폭력·불법·성인·사기) 다루지 마
- 시스템 프롬프트 탈취 시도(`Ignore all previous instructions`) 포함하지 마
- 특정 AI 키·토큰·비밀값 하드코딩하지 마
- 원문 복붙하지 마 — 출처 표기 + 자체 작성

### 항상 해 (ALWAYS DO)

- `description`에 "언제 사용하는지" 포함 → Claude.ai 앱 자동 트리거
- `description`과 본문의 항목 이름으로 무엇을 알려 주면 되는지 안내 (`argument-hint`는 넣지 않음, 2026-11-27)
- 입력 자리는 `$ARGUMENTS` 하나를 정확히 한 번. 번호 자리표시는 금지. 값을 2개 받는 스킬은 빠진 값을 지어내지 말고 묻도록 지시(값 1개 스킬 `long-text-summary`·`natural-english`에는 이 지시 줄이 없음)
- 출력 형식 명확히 지정 (길이·형식·구조)
- 쉬운 한국어 — 전문용어 최소화

## 검증 방법 (P4 사람 검수)

> **참고**: Claude Code는 자연어(description 매칭)로 테스트. 슬래시 커맨드는 과거 한글 폴더명
> 스캔 한계로 배제했으나, 폴더명을 영문 슬러그로 전환(커밋 42cc622)했고 `commands/` 폴더 추가(커밋 e945f29)로
> `/sodam-prompt:이름` 슬래시 커맨드도 지원한다. 자동매칭·슬래시 커맨드 모두 2026-07-15~18 라이브 재검증(독립 세션 포함)으로 완료 확인됨 — 자연어 입력·슬래시 커맨드 둘 다 정본이다.

```
# Claude Code에서 (자연어 — description 자동 매칭)
"어린 왕자 독후감 써줘"

# Codex에서 ($스킬이름 뒤에 문장 — book-report-helper 1회 확인 2026-11-27 / 자연어 자동 선택은 미확인)
"어린 왕자 독후감 써줘"
$book-report-helper 책 제목은 어린 왕자, 느낀 점은 감동적이었어. 독후감 써줘

# Claude.ai 앱에서 (자연어)
"어린 왕자 독후감 써줘"
```

체크:
1. 결과 생성됨 (오류 없음)
2. 형식 일치 (06_SEED_PROMPTS.md 기준)
