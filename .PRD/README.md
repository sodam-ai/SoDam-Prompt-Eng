## 한 장 요약
- **목적(고정)**: 프롬프트 엔지니어링을 완전 초보(비개발·만14세이상·AI처음)도 안전하게 쉽게.
- **핵심 구조(플러그인 전용, 2026-06-29 전환)**: 서버·DB·로그인 없음. GitHub 저장소=마켓, 실제 실행은 사용자 AI 도구가 담당. → 연령·동의·봇·비용·RLS·COPPA/GDPR 이슈 자체가 사라짐.
- **설치/작동(정체성)**: GitHub README=마켓(발견·예시) + 프롬프트를 **SKILL.md로 내 AI 도구에 설치**해 반복 사용(초보는 무코드 ZIP ★1). → [05_MARKETPLACE_PLUGIN.md](./05_MARKETPLACE_PLUGIN.md)
- **차별화**: **작동 검증 배지**(MVP="사람이 검수함". Phase2=로컬 promptfoo 형식 검사 결과를 수동 반영하는 절차만 있고 숫자는 없음).
- **안전(출시 차단)**: 순수 텍스트(무코드)·개인정보 유도 없음·위험주제 제외·AI 생성물 면책. → 서버/DB/키 없으므로 RLS·출력 모더레이션·예산한도는 해당 없음.
