1. 이게 대체 뭔가요?

SoDam Prompt(소담 프롬프트)는 AI(인공지능)에게 “이렇게 써줘”라고 말할 때 쓰는 미리 만들어진 질문 종이 10장입니다.

쉽게 비유하면: 학교에서 나눠주는 “빈칸 채우기 시험지”와 같습니다. - 시험지에 빈칸이 2~3개 있고 - 빈칸을 채워서 선생님(AI)에게 내면 - 선생님이 완성된 글(독후감, 메시지 등)을 써서 돌려줍니다

돈이 드나요? 이 종이(스킬 파일) 자체는 완전히 무료입니다. 다만 AI를 쓰려면 AI 서비스(Claude 등)에 가입해야 하는데, 그 가입·이용료는 이 프로젝트와 상관없이 AI 회사가 정합니다.

코딩을 알아야 하나요? 전혀요. 이 문서를 처음부터 끝까지 따라오시면 됩니다.

2. 사전 준비물

시작하기 전에 아래 3가지가 있는지 확인하세요.

준비물 왜 필요한가요? 없다면?
인터넷이 되는 컴퓨터 또는 노트북 프로그램을 설치하고 파일을 받아야 합니다 스마트폰만으로는 일부 방법(Claude.ai 앱)만 가능합니다
AI 서비스 계정 (예: Claude, ChatGPT 등) 실제로 글을 써주는 건 AI입니다 claude.ai에서 무료로 가입 가능합니다
이메일 주소 AI 서비스 가입에 필요합니다 없으면 먼저 이메일부터 만드세요 (Gmail 등)

용어 설명 - “컴퓨터”: 여러분이 지금 이 글을 읽고 있는 기기(윈도우 PC, 맥북 등) - “AI(인공지능)”: 사람처럼 글을 이해하고 써주는 컴퓨터 프로그램 (Claude, ChatGPT 등) - “계정(로그인)”: 이메일과 비밀번호로 만드는 나만의 온라인 신분증

3. 필요한 프로그램 설치하기

가장 쉬운 방법은 프로그램을 아예 설치하지 않는 것입니다. 아래 “방법 A”만 따라 하시면 설치가 필요 없습니다.

방법 A — 아무것도 설치 안 하기 (추천, ★가장 쉬움)

  1. 인터넷 브라우저(크롬, 엣지 등)를 엽니다.
  2. 주소창에 claude.ai 라고 입력하고 엔터를 누릅니다.
  3. 화면에 나오는 안내대로 이메일로 가입(또는 로그인)합니다.

이게 전부입니다. 프로그램 설치가 필요 없습니다.

방법 B — 개발자용 프로그램(Claude Code)을 쓰고 싶다면 (선택, 다소 어려움)

이 방법은 컴퓨터를 다뤄본 경험이 있는 분께 추천합니다. 처음이시라면 방법 A만 하셔도 충분합니다.

  1. 브라우저에서 nodejs.org 접속 → LTS라고 써 있는 버튼 클릭 → 다운로드

  2. 다운로드된 파일을 더블클릭 → “다음(Next)”을 계속 눌러 설치

  3. “검은 창”(터미널)을 엽니다: 윈도우는 시작 메뉴에서 “cmd” 검색, 맥은 “터미널” 검색

  4. 검은 창에 아래 글자를 그대로 입력하고 엔터:

    npm install -g @anthropic-ai/claude-code

  5. 설치가 끝나면 아래 글자를 입력해 확인:

    claude --version

    버전 숫자가 나오면 성공입니다.

4. 파일 다운로드 방법

  1. 브라우저에서 이 프로젝트의 인터넷 주소(GitHub 페이지)로 이동합니다.
  2. 화면 위쪽에 있는 초록색 “Code” 버튼을 클릭합니다.
  3. 메뉴가 나오면 “Download ZIP”을 클릭합니다.
  4. 다운로드된 압축 파일을 찾아 (보통 “다운로드” 폴더) 더블클릭해서 압축을 풉니다.
  5. 압축을 풀면 SoDam-Prompt-Eng-main 이라는 이름의 폴더가 생깁니다. 이 폴더 안에 skills라는 폴더가 있으면 성공입니다.

압축 풀기가 뭔가요? ZIP 파일은 여러 파일을 하나로 묶어놓은 “선물 상자” 같은 것입니다. 더블클릭하면 상자 안의 내용물(폴더와 파일들)이 꺼내집니다.

5. 5분 만에 첫 결과 받아보기 (빠른 시작)

방법 A(설치 없음)를 하셨다면, 아래 순서로 5분이면 첫 결과를 받습니다.

1단계: claude.ai 에 로그인 → 화면 오른쪽 위 내 프로필 아이콘 클릭 → “Customize”(사용자화) 클릭

2단계: 왼쪽 메뉴에서 “Skills”(스킬) 클릭 → “+ Create skill”(스킬 만들기) 버튼 클릭

3단계: 4번에서 다운로드한 폴더 안 skills 폴더를 열어, 원하는 스킬 폴더(예: 독후감-도우미) 하나를 통째로 업로드합니다.

4단계: 업로드된 스킬 옆의 토글(켜고 끄는 스위치)을 ON으로 켭니다.

5단계: 채팅창에 이렇게 말해보세요:

어린 왕자 독후감 써줘. 여우와의 만남이 인상 깊었어.

AI가 3문단짜리 독후감을 써주면 성공입니다!

6. 실행 방법 — 하나씩 그림 없이 설명

이 프로젝트를 “쓰는” 방법은 딱 하나입니다: AI에게 사람 말로 자연스럽게 부탁하는 것.

버튼을 누르거나 복잡한 명령어를 외울 필요가 없습니다. 마치 사람 비서에게 부탁하듯이 말하면 됩니다.

예시: - “정중한 메시지 하나 써줘, 팀장님한테 월차 신청하는 내용으로” → 정중한-메시지 스킬이 자동으로 반응합니다 - “이 긴 글 3줄로 요약해줘” (+ 요약할 글 붙여넣기) → 긴글-3줄요약 스킬이 반응합니다

왜 이렇게 되나요? 각 스킬 파일 안에는 “이런 말을 하면 나를 써줘”라는 설명이 들어있어서, AI가 알아서 골라 씁니다.

10. 파일이 어디에 저장되나요?

  • 다운로드한 원본 폴더: 여러분이 압축을 푼 그 위치 그대로 (예: 다운로드\SoDam-Prompt-Eng-main)
  • Claude.ai 앱에 올린 스킬: 여러분 컴퓨터가 아니라 Claude.ai 서버 안에 저장됩니다 (온라인 계정에 저장되는 것과 같습니다)

중요: 이 프로젝트는 여러분의 개인정보를 저장하는 서버가 없습니다. 여러분이 입력한 내용은 AI 회사(Anthropic 등)의 서버로만 전달됩니다.

12. 보안은 안전한가요? (쉬운 설명)

네, 안전합니다. 이유는 3가지입니다.

  1. 이 스킬 파일들은 순수한 “질문 종이”입니다. 컴퓨터에서 프로그램을 실행하거나, 파일을 지우거나, 다른 곳에 몰래 접속하는 코드가 전혀 없습니다.
  2. 개인정보(이름·전화번호·주소)를 물어보지 않습니다. 10개 스킬 전부 확인했습니다.
  3. 위험하거나 민감한 주제(의료·법률·금융·자해·성인물)를 다루지 않도록 설계되었습니다.

다만 이건 꼭 지켜주세요: - AI 채팅창에 진짜 개인정보(전화번호, 집 주소, 비밀번호)를 입력하지 마세요. - 반드시 공식 GitHub 저장소(sodam-ai/SoDam-Prompt-Eng)에서만 받으세요. 다른 곳에서 받은 파일은 내용이 바뀌었을 수 있습니다.

더 자세한 보안 구조가 궁금하시면 README.md 10장을 참고하세요.

14. 자주 묻는 질문 (FAQ)

Q: 완전 공짜인가요? A: 이 스킬 파일 10개는 완전 무료입니다. 다만 AI 서비스 자체의 유료/무료 정책은 AI 회사(Anthropic 등)가 정합니다.

Q: 회원가입을 꼭 해야 하나요? A: 이 프로젝트 자체는 회원가입이 필요 없습니다. 다만 AI(Claude 등)를 쓰려면 그 서비스에 가입해야 합니다.

Q: 제 개인정보가 어딘가에 저장되나요? A: 아니요. 이 프로젝트는 서버가 없어서 아무것도 저장하지 않습니다. 여러분이 입력한 내용은 AI 회사 서버로만 전달됩니다.

Q: 스마트폰으로도 되나요? A: 네, Claude.ai 앱(모바일)으로 가능합니다. 다만 스킬 업로드는 컴퓨터 브라우저가 더 편합니다.

Q: 결과가 이상하게 나오면 제 잘못인가요? A: 아닙니다. AI는 완벽하지 않을 수 있습니다. 결과를 그대로 믿지 말고 한 번 더 확인하는 습관을 들이세요.
